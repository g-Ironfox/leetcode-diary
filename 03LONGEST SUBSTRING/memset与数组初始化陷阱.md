# memset 与 C 语言数组初始化陷阱

[Hash 查重与复杂度降阶](./Hash查重与复杂度降阶.md) · [滑动窗口](./滑动窗口.md) · [最长子串题解](./LONGEST%20SUBSTRING.md)

> 以 `6_correct_expanding_window.c` 中 `memset(seen, -1, sizeof(seen));` 为实例，解释为什么 `int seen[128] = {-1};` 是错的，以及 `memset` 在这里为什么能正确工作。

---

## 一、陷阱：`int arr[N] = {-1}` 不是全 -1

```c
int seen[128] = {-1};   // ❌ 只有 seen[0] = -1，其余 127 个全是 0
```

C 标准规定：初始化列表中的值按顺序赋给数组前几个元素，**未显式指定的剩余元素全部初始化为 0**（对于算术类型）。

等价于：

```c
int seen[128] = {-1, 0, 0, 0, ..., 0};  // 128 个元素
//                ↑   ↑  ↑  ↑       ↑
//               -1   0  0  0       0
```

### 实际问题

在 `6_correct_expanding_window.c` 中，`seen` 用来记录字符上次出现的位置，用 `-1` 表示"未出现过"。如果用了 `= {-1}`：

- `seen['a']` = `seen[97]` = **0**（不是 -1）
- `if (seen[(unsigned char)s[right]] != -1)` → `0 != -1` 为真 → 立即 break
- 结果：几乎所有输入都返回 0

---

## 二、为什么 `memset(seen, -1, sizeof(seen))` 可行

```c
int seen[128];
memset(seen, -1, sizeof(seen));   // ✅ 每个 int 都是 -1
```

### `memset` 按**字节**填充

`memset(ptr, val, n)` 把 `val` 截断为 `unsigned char`，然后写入连续的 `n` 个字节。`-1` 截断为 `unsigned char` 就是 `0xFF`。

`sizeof(seen)` = `128 × sizeof(int)` = `128 × 4` = **512 字节**。所以这行代码把 512 个字节全部写成 `0xFF`。

### 为什么 `0xFF` 四个字节拼起来正好是 `int` 类型的 `-1`

在补码（two's complement）表示下，`int` 类型的 `-1` 的二进制表示就是全 `1`：

```
int (-1) = 0xFFFFFFFF  （32 位系统）
            FF FF FF FF
```

每个字节都是 `0xFF`，所以逐字节写入 `0xFF` 恰好得到每个 `int` 都是 `-1`。

---

## 三、`memset` 的通用局限

`memset` 只在两种情况下对 `int` 数组有效：

| 目标值 | 每字节写入 | 最终 int 值 | 原理 |
|--------|-----------|-------------|------|
| `0` | `0x00` | `0x00000000` = 0 | 所有位都是 0 |
| `-1` | `0xFF` | `0xFFFFFFFF` = -1 | 所有位都是 1 |

**其他值不能用 `memset`**：

```c
int arr[10];
memset(arr, 1, sizeof(arr));   // ❌ arr[i] = 0x01010101 = 16843009，不是 1
```

因为 `memset` 按字节填充，`1` 作为 `unsigned char` 是 `0x01`，填入每个字节后四个字节拼成 `0x01010101`，这在 `int` 中表示的是 16843009，不是 1。

正确初始化其他值必须用循环或 `for`：

```c
for (int i = 0; i < 128; i++) seen[i] = -1;   // 通用但稍慢
```

---

## 四、什么时候用哪个

| 场景 | 方法 | 原因 |
|------|------|------|
| 全 0 | `int arr[N] = {0};` | 简洁，编译器优化 |
| 全 -1 | `memset(arr, -1, sizeof(arr));` | 快速，按字节填充恰好正确 |
| 全 -1（少量元素） | `int arr[128] = { [0 ... 127] = -1 };` | GCC 扩展，可读性好 |
| 其他值 | `for` 循环 | `memset` 不可用 |
| 动态数组 (`malloc`) | `memset` 或 `calloc`（仅 0 值） | 没有初始化列表语法 |

---

## 五、总结

`int seen[128] = {-1};` 是 C 语言中最容易踩的坑之一——看起来像是把整个数组初始化为 -1，实际上只初始化了第一个元素。`memset(seen, -1, sizeof(seen));` 利用补码中 -1 全 `1` 的性质，通过逐字节写入 `0xFF` 巧妙地实现了全 -1 初始化。但记住这种"巧合"仅对 `0` 和 `-1` 有效。
