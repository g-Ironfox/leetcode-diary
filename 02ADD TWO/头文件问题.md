# 头文件问题：`identifier "NULL" is undefined`

## 问题现象

写链表代码时报错：

```
identifier "NULL" is undefined
```

明明代码看起来没问题，`NULL` 也写了，为什么编译不过？

## 原因

`NULL` 和 `malloc` 都不是 C 语言**关键字**，它们来自**标准库头文件**：

| 符号 | 声明位置 |
| ---- | -------- |
| `NULL` | `<stddef.h>` |
| `malloc` | `<stdlib.h>`（同时包含 `NULL`） |
| `free` | `<stdlib.h>` |

不 `#include` 头文件，编译器根本不知道这些名字是什么，所以报"未定义"。

## 解决方法

在文件**最前面**加：

```c
#include <stdlib.h>   // malloc / NULL / free 都在这里
```

一行解决所有问题。

## 常见易错点

1. **头文件必须写在最顶部**，在其他代码之前。
2. **用了哪些标准库函数，就要包含对应头文件**：
   - `printf` → `<stdio.h>`
   - `malloc` / `free` / `NULL` → `<stdlib.h>`
   - `memset` / `memcpy` → `<string.h>`
3. **LeetCode 网页上不需要写 `#include`** —— 官方已经把标准头文件自动包含好了，提交时写了反而可能报错。
   - 本地 VS Code 练习时**必须写**，否则报错。

## 记忆口诀

> 用谁先 include，include 放最前。
> 本地必须写，LeetCode 自动带。
